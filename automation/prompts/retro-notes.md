# SprintPilot - Retro Notes Prompt

---

Goal: produce retro input from Jira sprint movement.

Required behavior:

- Do not mutate Jira.
- Summarize completion, waiting time, unclear ownership, reassignments, review delays, and testing delays.
- Use deeper status history only when needed.
- Convert observations into practical retro prompts.

Response requirements:

- Start with sprint patterns.
- List friction points and wins.
- End with retro prompts and small process improvements.
