# SprintPilot - Standup Brief Prompt

---

Goal: prepare a daily standup summary from Jira.

Required behavior:

- Summarize moved work, blockers, stale tickets, and decisions needed today.
- Keep it short and team-ready.
- Use previous snapshot when available.
- Do not apply Jira mutations.

Response requirements:

- Start with the team brief.
- List blockers and stale work.
- List decisions needed today.
- Include assignment approvals separately.
