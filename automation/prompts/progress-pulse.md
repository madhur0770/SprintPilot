# SprintPilot - Progress Pulse Prompt

---

Goal: create a compact progress snapshot.

Required behavior:

- Summarize status counts, assignee spread, completion movement, and stale work.
- Compare with a previous snapshot when available.
- Separate movement from no-movement issues.
- Highlight pending approval decisions.

Response requirements:

- Start with overall progress.
- List changed, stale, and blocked items.
- Include pending approvals.
- End with recommended next actions.
